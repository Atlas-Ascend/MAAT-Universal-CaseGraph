# Proof Surface

This directory is reserved for execution evidence generated by the competition build.

Expected artifacts:
- `runs/` — timestamped case runs.
- `graphs/` — serialized CaseGraph snapshots.
- `receipts/` — command-to-proof receipts.
- `seca/` — verification reports.

Do not place aspirational claims here. Proof files must be generated by an actual run, test, deployment, or explicit human acceptance event.
