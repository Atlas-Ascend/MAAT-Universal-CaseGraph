# 04 — Use Cases

1. **Project triage** — requirements, owners, blockers, deadlines, and changed scope.
2. **Client case intake** — people, claims, evidence, obligations, unresolved facts.
3. **Incident reconstruction** — timeline, symptoms, hypotheses, evidence, remediation tasks.
4. **Research synthesis** — sources, claims, support/conflict relationships, evidence gaps.
5. **Operational handoff** — convert narrative context into owners, dependencies, acceptance criteria, and receipts.

The hackathon demo uses project triage because the causal chain is visible immediately.
