# 01 — Mission

## Mission
MAAT turns ambiguous, fragmented human situations into explicit, inspectable, dependency-aware cases that can drive bounded action.

## Transformation
`unstructured context -> normalized facts -> typed graph -> reasoning -> plan -> action -> verification -> receipt`

## Non-goals
- Not a generic chat wrapper.
- Not an autonomous authority over irreversible actions.
- Not a replacement for the broader Ghost Atlas estate.

## Proof criterion
Given a messy input bundle, MAAT must emit a case graph, identify at least one actionable dependency or evidence gap when present, select a next-best action, and produce a receipt linking the recommendation to graph evidence.
